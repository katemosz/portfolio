Drop anything here that inspires the visual direction of the site:
screenshots of other portfolios/sites you like, mood-board exports,
sketches, whatever. Any filenames, no organization needed.

You can also just paste links or images directly in the chat instead —
both work equally well. This folder is just for anything that's easier
to save as a file than to paste.

Note: this folder isn't linked from the site anywhere, but since it
lives inside the same folder that gets pushed to GitHub, treat it like
everything else here — nothing truly private.
